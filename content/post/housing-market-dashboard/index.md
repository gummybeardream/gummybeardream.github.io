Designed a scalable data pipeline in Python to process 76,000+ rows of Zillow housing records, leveraging Pandas for data cleaning and Matplotlib to visualize KPIs and support trend analysis

Developed an interactive Tableau dashboard to analyze price trends, seasonality, and regional growth, supporting strategic investment and homebuyer decisions

Imputed 6,400+ missing values using city-level medians to improve data integrity and produce accurate visualizations for year-over-year comparisons
